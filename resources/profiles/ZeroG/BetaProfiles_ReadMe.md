### If you previously installed any older version of the profiles from ZeroG Discord you will have to clean up Orca for the New ones to work.

If you do not clean older files Orca Slicer won't copy the new files to your AppData folder and you won't see any changes.

##### Windows users.

Go into:
```%appData%\OrcaSlicer\system``` (Usually located at: ```C:\Users\username\AppData\Roaming\OrcaSlicer\system```)
Delete the file ```ZeroG.json``` and the Folder ```ZeroG```.

To backup your user setting files before installing, make a copy of your files under:
```%appData%\OrcaSlicer\user\default``` (Usually located at: ```C:\Users\username\AppData\Roaming\OrcaSlicer\user\default```)
